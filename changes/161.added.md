**Routines come with a short setup checklist.** When you set up something that repeats or waits for an event,
Sentient fills in a checklist from its plan: when it runs and in which time zone, what it reads, what you get, whether
it may go ahead or should ask you first, and what to do when the page, app or folder it reads isn't there (skip
quietly, tell you, or try again a little later). Confirm it as it is or change any answer, and use Try it first right
there to see what it would do without sending, changing or running anything. A run skipped because what it reads
was missing now shows as Skipped in the run history, with the reason, instead of failing quietly.
