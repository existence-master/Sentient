**Every memory shows where it came from, how sure Sentient is, and whether it still holds.** Open a memory to see each
place that told Sentient, with the words it said, and jump straight to that chat message, email or note. Sentient gets
surer each time something says it again, and you can mark a memory as not right so it stays out of chats and tasks.
When a newer memory replaces an old one, the old one is kept as history instead of disappearing. Deleting a memory now
also removes what was built from it: chat summaries, the nightly journal's notes, insights about you and the lines in
USER.md and MEMORY.md. Memories learned in Telegram, Discord, WhatsApp or on a device before this update now say so.
