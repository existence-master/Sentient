**Other apps can chat with Sentient through an OpenAI-compatible API.** An editor, script or shortcut that speaks
the OpenAI API can get Sentient's replies, with its memory and tools, in a chat of its own. Anything that needs
your OK still asks you in Sentient (and on your phone when you're away), and the app hears plainly when something
wasn't done. Requests from another app never count as your personal permission to run code or send data out.
It is off until you turn it on, and each app needs Sentient's API key.
