**Other apps can chat with Sentient through an OpenAI-compatible API.** An editor, script or shortcut that speaks
the OpenAI API can get Sentient's replies, using its tools, in a chat of its own. It doesn't get your memories,
profile or past chats unless you turn on "Let connected apps use my memories". Anything that needs your OK still
asks you in Sentient (and on your phone when you're away), and the app hears plainly, first, when something wasn't
done. Requests from another app never count as your personal permission to run code or send data out, and
deleting something always asks you first. Turn it on, make the app's key and see its address in Settings >
Advanced > Connected apps.
An app gets a clear busy reply when its chat is already replying.
Stop catches requests that are still starting and clears interrupted approvals. History and memory summaries
keep track of words that came from another app.
It works only on this computer, is off until you turn it on, and each app needs Sentient's API key.
