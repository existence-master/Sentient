**Teach Sentient a skill from your docs with `/learn`.** Type `/learn` with a link, a file or a folder of notes in
chat (or in Telegram, Discord or WhatsApp), and Sentient drafts a skill from it for you to review. Long docs keep their
full text in reference files that Sentient reads only when it uses the skill, and a page's own instructions are never
followed: the draft waits with a safety check until you approve it.
