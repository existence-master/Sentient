**Sentient now corrects itself when it claims a send, save, booking or home action happened but it didn't.** If an email, message, file write, calendar event or smart-home action was declined, failed, or never attempted, the reply says so plainly instead of claiming it worked. True reports are left alone when the records confirm them, and when it can't tell, it says it couldn't confirm rather than correcting. Voice and channel replies get the same correction.
