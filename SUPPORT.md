# Getting help

- **Using Sentient:** start with [Getting started](docs/GETTING_STARTED.md), including its troubleshooting table.
- **Questions and setup help:** ask in [Discussions → Q&A](https://github.com/existence-master/Sentient/discussions/categories/q-a).
  You never need our API keys: Sentient runs on a free local model or your own key.
- **Bugs and feature requests:** [open an issue](https://github.com/existence-master/Sentient/issues/new/choose).
- **Security problems:** report privately, see [SECURITY.md](SECURITY.md).

When asking for help, include your operating system, Sentient version, the model you use, and the end of
`~/.sentient/logs/backend.log` with personal details removed.
